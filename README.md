## 🔄 Système de Mise à Jour Automatique

Les applications Desktop (macOS et Windows) intègrent la détection et la mise à jour automatique via ce dépôt public. À chaque nouvelle publication d'une version balisée (`vX.Y.Z`), les applications clientes notifient l'utilisateur et peuvent appliquer le patch sans réinstallation manuelle.
